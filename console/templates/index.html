Servo commands

Straight down the serial link. A two-letter servo code followed by a value, nothing in between: HH50 absolute percent of travel, HH+5 relative, DP for default positions. Several separated by spaces move together. Up and down recall what you sent before.

Head HH HV HM · right arm RB RW RT RI RM RR RP · left hand LW LT LI LM LR LP. The firmware clamps to each servo's own limits, and answers E100 for a code it does not have.
